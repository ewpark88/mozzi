## GDD 수정 제안 (사용자가 원본에 반영)

**GDD 파일은 Claude 가 직접 고치지 않는다** (2026-09-28 결정). 사용자가 다른 원본에서 GDD 를 통째로 덮어쓰므로
직접 수정은 세 번 모두 되돌아갔다. 아래 제안은 사용자가 원본에 반영하고, 코드는 ADR 을 따른다.
